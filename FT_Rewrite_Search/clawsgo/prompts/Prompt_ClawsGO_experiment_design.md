# 已经确定的事实（都已核对过原文，请直接作为前提）
- FE 重写规则（Rodatz, Poór, Kissinger, arXiv:2506.17181）能保证改写前后 fault-equivalent，所以搜索过程中不用重新验证容错。完备性论文（Rüsch et al., arXiv:2510.08477）给出了唯一范式；判定 FE 是 NP-hard。
- 最近的竞争工作 Jeon et al.（arXiv:2610.09749）在电路层面用了四条规则：受限交换、basis swap、target swap 三条使能规则，加上 Bell reduction（每次删 1 个辅助比特和 1 个 CNOT）。搜索算法是 BFS，不去重；使能规则只在能"立即暴露 Bell 对"时才用，不允许多步串联。只做了 [[7,1,3]]：Shor 型每个 gadget 只有 7 个可达电路（5 个辅助比特、9 个 CNOT 降到 3 个、7 个），Steane 型生成 391 个候选，用分阶段蒙特卡洛淘汰（10³ → 10⁶ shots）。噪声模型：两比特门 p，单比特门 3p/100，SPAM p，空闲 p/10；解码用 flag 条件查表。代码仓库 ijshj10/ftzx 目前打不开。
- FE 只保证最坏情况（查不出的故障集合和权重），不保证逻辑错误率（LER）不变。所以 FE 是约束，不是目标；ML 的职责是排序和剪枝，不是回归 LER 的绝对值。
- [[7,1,3]] 已接近饱和（Poór et al., arXiv:2511.13700 证明主电路 14 个 CNOT 是下界），只用来复现。主要目标是 [[17,1,5]] 色码（基线：Liou et al., arXiv:2407.00607 的 flag-sharing 电路）和一个小型 qLDPC 码；[[15,1,3]] 作备选。
- 构造式基线：SpiderCSS（arXiv:2610.03714）、Transversal SE（arXiv:2610.30279）、ASC / LocalASC（arXiv:2603.21499、2609.40319）。
- LER 估计的可选方法：重要性采样 / subset sampling（Heußen et al., arXiv:2309.12774）、rare event simulation（Mayer et al., arXiv:2509.13678）、Fail Fast（Beverland et al., arXiv:2511.15177）。
- RL + ZX 的已知教训：只学策略、不配树搜索，会退化成只输出 NO-OP（Mattick et al., arXiv:2504.03429）；把确定性的规则闭包嵌进环境效果更好（arXiv:2608.19103）。
